# Security Policy

## Supported Versions

Currently, only the latest major release of the Mindful Breathing Visualizer is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 3.x.x   | :white_check_mark: |
| 2.x.x   | :x:                |
| 1.x.x   | :x:                |

## Reporting a Vulnerability

Security is a top priority for this project. If you discover a vulnerability, we would like to know about it so we can take steps to address it as quickly as possible.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to the maintainers directly via email or private channels. If you have an email address for the repository owner, please use that. Otherwise, please open a private vulnerability report via GitHub Security Advisories if the feature is enabled.

### What to include in your report

*   **Description:** A detailed description of the vulnerability.
*   **Steps to reproduce:** Please include step-by-step instructions or a proof of concept.
*   **Impact:** What is the potential impact of this vulnerability?
*   **Suggested Mitigation:** If you have suggestions on how to fix the issue, please include them.

### Response Time

We strive to acknowledge all reports within 48 hours and will keep you informed of our progress towards a fix. We will notify you when the issue is resolved and will publicly acknowledge your contribution (if you desire) once a patch has been released.
