# Mindful Breathing (Ruby Gem)

A simple Ruby CLI for mindful breathing exercises.

## Installation

```bash
gem build mindful_breathing.gemspec
gem install mindful_breathing-0.1.0.gem
```

## Usage

```bash
mindful_breathing
```

Follow the on-screen prompts to select your breathing technique.
