# The Mindful Terminal

A bash-based command line breathing visualizer.

## Usage

1.  Make the script executable: `chmod +x breathe.sh`
2.  Run: `./breathe.sh`
3.  Enjoy the ASCII circle animation.
4.  Press `Ctrl+C` to exit.

## Requirements

- `bash`
- `bc` (for floating point math)
- `tput`
