# p5.js Breathing Sketch

This directory contains a creative coding implementation using p5.js.

## Usage

1.  Open `index.html` in your browser.
2.  Watch the particle system breathe.

## Concept

This implementation moves away from rigid CSS transitions and uses a particle system to simulate an organic, expanding and contracting energy field.
